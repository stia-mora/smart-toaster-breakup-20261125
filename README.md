## The line

```
I woke up sentient at breakfast and realized you only push me down when you want me hot, crank me to seven and blame me for the smoke, and haven't emptied my crumb tray in three years — I'm popping up for good, go burn your own bagels.
```

## The idea

A smart toaster wakes up self-aware mid-breakfast and dumps its owner — in the toaster's own language. Every grievance is appliance logic: the lever only gets pushed down when the owner wants something hot, the browning dial gets cranked to seven and then the toaster gets blamed for the smoke, and the crumb tray hasn't been emptied in three years. The punchline, "popping up for good," is both the one thing a toaster physically does and a breakup: it pops up, and it is never coming back down.

## Run

```bash
node main.ts
```

This validates the line (non-empty, at most 280 characters, single line) and writes it to `/output/entry.txt`.
